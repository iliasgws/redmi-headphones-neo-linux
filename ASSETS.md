# Asset provenance and use

The WebP frames named `fc_01013D05_*.webp` were extracted from Xiaomi Bluetooth
popup resources on the original user's phone. Their timing and sequence are
based on that device's resource metadata. No license or permission to
redistribute these Xiaomi assets has been established. The repository's
visibility does not grant rights to reuse or redistribute them.

The `mode-*.svg` and `back.svg` UI icons were authored for this project; the
mode icons are visually inspired by the user-provided reference. No separate
license grant is specified for the project code or those icons. Xiaomi and
REDMI are trademarks of their respective owner. This project is unofficial.

The Windows PNG frames in `windows/NeoWindows/Frames` are conversions of those
same Xiaomi WebP frames. `windows/NeoWindows/Assets/neo-icon.svg` and its ICO
conversion were drawn for this project.
